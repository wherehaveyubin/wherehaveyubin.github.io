Paper Review

A personal reference manager for academic papers, for desktop (Windows and macOS).

Paper Review keeps a researcher's library of PDF papers in one place: metadata, folders, highlights and notes made on the PDFs, and AI-assisted summaries.

The library lives in the user's own Google Drive. Paper Review signs in with the user's Google account so that it can download the library to the computer when the app opens and upload the changes when it closes, keeping the same library in step across the user's own computers and tablet.

It is a personal project, used by its developer. It is not sold or offered as a service.
